The official personal portfolio of **Abhinandan Mishra**, Software Engineer II at **Project44**. Designed for maximum speed, clean typography, zero heavy client JavaScript, and seamless integration with [Abhinandan's Technical Blog](https://blog.abhinandanmishra.in).

## Features

- **Blazing Fast:** Built with Next.js 15 App Router and React 19 Server Components.
- **SDE-2 Flagship Showcase:** Highlights production products including SDE Forge, CodePad, AI Shipment Copilot, 100xHires, and Model Context Protocol servers.
- **Continuous Learning & Research:** Dedicated architectural research section covering distributed systems (DDIA), database isolation levels, caching strategies, and algorithms.
- **Algorithmic Honors:** Highlights competitive programming milestones (Google Kickstart, Codechef Starters, ACM-ICPC, LeetCode Knight 2026 rating).
- **Dark/Light Mode:** Seamless theme switching with `next-themes` and zero flash.
- **Connected Ecosystem:** Deep integration with the separate blog repository (`blog.abhinandanmishra.in`).

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production build
npm run start
```

## Environment Variables

```env
NEXT_PUBLIC_BLOG_URL=https://blog.abhinandanmishra.in
```
